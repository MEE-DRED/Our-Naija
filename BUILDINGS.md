# Buildings

Agricultural processing buildings use the shared processing recipe system:

- Garri Processing Mill: garri, fufu, cassava flour, starch
- Rice Mill: milled rice, packaged rice
- Tomato Processing Facility: tomato paste, tomato sauce
- Maize Processing Facility: maize flour, maize meal, livestock feed

Each job consumes inventory, checks electricity and treasury, occupies the existing single processing capacity, advances on the pause-aware game clock, and adds output when collected. The React processing panel is reusable across facilities.
